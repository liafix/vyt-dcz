TEORETICKÝ ZÁKLAD

Žiadny pin
nesmie hádať.

Nepripojený digitálny vstup nemá zaručený stav. Rezistor ho jemne pritiahne k definovanej úrovni.

01

Plávajúci vstup (floating input)

Vstup nie je pevne pripojený na HIGH ani LOW. Zachytáva rušenie a jeho čítanie môže náhodne kolísať.

02

Pull-down drží LOW

Rezistor spája vstup s GND; tlačidlo ho po stlačení pripojí na +5 V. Uvoľnené = LOW, stlačené = HIGH.

03

Pull-up drží HIGH

Rezistor spája vstup s napájacou úrovňou; tlačidlo ho po stlačení pripojí na GND. Uvoľnené = HIGH, stlačené = LOW.

04

Arduino Uno má interný pull-up

pinMode(BUTTON_PIN, INPUT_PULLUP); aktivuje interný rezistor. Externý pull-up netreba; program musí počítať s obrátenou logikou.

VZOROVÝ PROGRAM

INPUT_PULLUP bez externého rezistora

Pripoj tlačidlo medzi D2 a GND. Interný pull-up zabezpečí pokojový HIGH stav.

ARDUINO IDE · LED SVETI PRI STLAČENÍ
const int LED_PIN = 8;
const int BUTTON_PIN = 2;

void setup() {
  pinMode(LED_PIN, OUTPUT);
  pinMode(BUTTON_PIN, INPUT_PULLUP);
}

void loop() {
  int buttonState = digitalRead(BUTTON_PIN);

  if (buttonState == LOW) {
    digitalWrite(LED_PIN, HIGH);
  } else {
    digitalWrite(LED_PIN, LOW);
  }
}

Pri INPUT_PULLUP je LOW aktívny stav: tlačidlo stlačené spája D2 s GND.

UČITEĽSKÉ POZNÁMKY · SKRYTÉ V POHĽADE ŽIAKA

Metodické vedenie hodiny

Riadený objav

Na začiatku sa žiakov opýtajte na výsledok čítania odpojeného vstupu; nech predikciu napíšu skôr, než spoločne pomenujete pojem floating input. Porovnanie vykonajte na bezpečnej doske a nikdy zámerne neskratujte napájanie.

Kľúčové pozorovanie

Pull-down: vstup sa v pokoji cez rezistor pripája ku GND, preto číta LOW; stlačené tlačidlo ho pripája na +5 V, preto číta HIGH. INPUT_PULLUP: pokojový HIGH; tlačidlo na GND dáva pri stlačení LOW.

Otázky a diferenciácia

„Ktorá cesta určí pokojový stav? Čo sa zmenilo v zapojení? Ktorý riadok musí zodpovedať aktívnej logickej nule?“ Podpora: použiť pripravenú tabuľku HIGH/LOW. Výzva: preniesť riešenie na dva nezávislé vstupy a otestovať oba naraz.
